# S.P.E.E.D.

## Smart Personalized Engineering Education & Development System

S.P.E.E.D. is a Java-based educational productivity system designed to help students manage their academic activities, track learning progress, manage tasks and projects, and receive personalized study recommendations.

## Project Goal

The goal of this project is to develop a real-world software system while applying Object-Oriented Programming, database management, backend development, analytics, and AI concepts.

## Planned Technologies

- Java
- Object-Oriented Programming
- MySQL
- JDBC
- Spring Boot
- REST API
- HTML
- CSS
- JavaScript
- AI
